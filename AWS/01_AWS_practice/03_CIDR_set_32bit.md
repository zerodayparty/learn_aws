# 🟩 CIDR /32 표기법의 의미  

## 🟢 /32를 사용하는 이유  

### 🟡 단 하나의 IP 주소 지정  

* IP 주소 체계(IPv4)는 총 32비트로 구성됨  
* `/32`는 32비트 전체가 네트워크 주소로 고정되었음을 의미함  
* 즉, IP 대역이 아닌 '정확히 지정된 단 1개의 IP 주소'만 허용하는 설정임  


### 🟡 접근 제어 및 보안 차단  

* SSH(22번 포트)는 서버 제어 권한을 갖는 매우 위험한 포트임  
* `0.0.0.0/0` 설정 시 전 세계 모든 IP에서 접근 시도가 가능해짐  
* `/32`를 통해 지정된 관리자의 IP(`121.135.181.35`) 외 모든 IP의 접근을 차단함  


#### ⚫️ 서브넷 마스크 비교  

| CIDR 표기 | 허용 IP 개수 | 대상 범위 |  
| --- | --- | --- |
| `0.0.0.0/0` | $2^{32}$ (4,294,967,296개) | 전 세계 모든 IP 주소 |  
| `121.135.181.35/32` | $2^0$ (1개) | `121.135.181.35` 단일 IP |

# 🟩 Tag & Naming Rules  

## 🟢 기준 표  

| 기준 | 사용값 | 목적 |  
| :--- | :--- | :--- |
| Project Tag | `Project=aws-basic-lab` | 같은 실습 리소스를 한 번에 검색 |  
| Name 규칙 | `aws-basic-lab-vpc`, `aws-basic-lab-subnet` 등 | 사람이 리소스 용도를 바로 구분 |  


## 🟢 1. Project 환경변수 지정  
- export PROJECT=aws-basic-lab  


## 🟢 2. 각각의 name 규칙들  
- aws-basic-lab 이 project 명칭을 기준으로 두고, 그 뒤에 직관적인 명칭을 붙인다.  
    - `aws-basic-lab-vpc`, `aws-basic-lab-subnet` 등
